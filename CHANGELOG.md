# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).


## [1.0.0] - 2026-01-04

### Added

- Initial release of `sirix/sirix-env`.
- Helper `env()` function for retrieving environment variables.
- `EnvParser` class for type casting environment variables.
- Support for type casting: `true`, `false`, `null`, `empty`, and numeric values.
